## 取り込み手順

```bash
# 1. 学習側でモデルが変わったなら MJCF とメッシュを持ってくる
cp $ISAAC/reference_model/big_rabbit_isaac.xml robotmodel/big_rabbit/big_rabbit.xml
cp $ISAAC/reference_model/meshes/*.STL       robotmodel/big_rabbit/meshes/

# 2. Makefile の POLICY_RUN / POLICY_PARAMS を新しい版へ
# 3. ヘッダを生成（重み・config・参照テーブル）
make export

# 4. クロス検証
make test verify hold tracking
make walk        # 段 6

# 5. 足裏形状を目で確認
make foot        # outputs/foot_collision.png と foot_overlay.png
```

**モデルを差し替えたら足裏カプセル軸の水平を必ず確認する。**
軸は世界座標で厳密に `[1, 0, 0]`、hip_roll を -15..+15 deg 振っても z 成分が 0 でなければならない。
足首にロール自由度がない（BDX と同じ）ので、これが崩れると内側エッジで接地して
sim と実機がずれる。

## 学習側の観測ノイズは deploy には出てこない

v24 で入れた接地誤検出（miss 0.05 / false 0.02）と `base_height` のノイズ・バイアスは
**学習時の観測破損**で、`isaac_policy_config.h` には現れない。
deploy 時は実センサが誤差を供給する側なので、ブリッジが乱数を足す必要はない。

この設計のおかげで、実機の接地判定が多少信用できなくても policy が耐える。
ブリッジ側で作り込む必要があったものが学習側へ移った、という理解でよい。
